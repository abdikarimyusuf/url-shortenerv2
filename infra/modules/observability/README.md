## HTTP 4XX vs 5XX Errors

4XX = Client / Request-side error

The server received the request,
but the request cannot be fulfilled as made.

Common 4XX errors:

400 Bad Request
    → Request is invalid or malformed
    → Example: Invalid JSON sent to the API

401 Unauthorized
    → Authentication is missing or invalid
    → Example: Missing or expired login token

403 Forbidden
    → Request is understood, but access is not allowed
    → Example: User does not have permission

404 Not Found
    → Requested resource does not exist
    → Example: GET /users/999 but user 999 does not exist

405 Method Not Allowed
    → HTTP method is not allowed for that endpoint
    → Example: POST sent to an endpoint that only accepts GET

408 Request Timeout
    → Server waited too long for the request
    → Example: Client takes too long to send data

409 Conflict
    → Request conflicts with the current state
    → Example: Trying to create a username that already exists

429 Too Many Requests
    → Client has sent too many requests
    → Example: API rate limit has been exceeded
5XX = Server-side error

The server received the request,
but something went wrong while trying to process it.

Common 5XX errors:

500 Internal Server Error
    → Application encountered an unexpected error
    → Example: Application crashes while processing a request

502 Bad Gateway
    → Gateway/proxy received an invalid response from upstream
    → Example: ALB cannot get a valid response from the ECS application

503 Service Unavailable
    → Service is currently unavailable
    → Example: No healthy ECS tasks are available

504 Gateway Timeout
    → Gateway waited too long for the upstream service
    → Example: ALB waits too long for the ECS application
